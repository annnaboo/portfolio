04

Decisions & Consequences

A system only works if it survives real days. These choices made it stick.

Decision 01
Write for agents, not only for me
A constitution file and a registry of what lives where, read by every agent before it acts.
AI · Context
What happened
New sessions start with full context instead of a long explanation in chat.
Decision 02
Mark what the AI wrote
Every agent-created note carries an agent-written property.
Trust · Traceability
What happened
It is always clear which notes are my thinking and which are generated summaries.
Decision 03
One template for every project
Access, schema, bugs, tech debt and session log — the same set everywhere.
Consistency
What happened
Switching between seven projects stopped costing a warm-up hour.
Decision 04
Daily note with a summary
What worked, what didn’t, what’s next — written at the end of each day.
Habit · Reflection
What happened
Tomorrow’s priorities are ready before the day starts, and open loops are visible.

06

What I learned

Working with AI changed what “organised” means. Notes are no longer only for me to reread — they are the context an agent loads before it touches my code or designs.

Good AI output starts with good input. The constitution, the registry and the project templates do more for quality than any single prompt.

A second brain is a design system for thinking: shared rules, reusable templates, and one source of truth.

The biggest win was not speed. It was confidence: decisions, test results and open questions are written down, so nothing important lives only in my head.
