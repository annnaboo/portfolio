Architecture

Security lives in the database, not in the interface. Supabase row-level security decides who sees what, so every new screen is safe by default.

Roles
profiles.role — coach or client. Self-coach covers people who train themselves.
Identity
Data
Workouts with exercises (JSON), programs as ordered workout lists, a schedule per client.
★ Key layer
Security
RLS on every table: clients own their rows, the coach reads all.
Safe by default

  WHERE id = auth.uid()
  AND role = 'coach')

04

Decisions & Consequences

A pet project still needs product decisions. These shaped it the most.

Decision 01
Web first, as the reference
The web app is the “etalon”: every iOS screen is checked against it for parity.
Process · Parity
What happened
One source of truth for features and flows — iOS work became translation, not reinvention.
Decision 02
Go beyond parity where it matters
On iOS the coach can edit nutrition (macros); on the web it stays read-only.
Mobile-first coaching
What happened
The coach can adjust a client’s nutrition right after a session, from the phone.
Decision 03
Permissions in the database
Access rules are row-level security policies, not checks in the UI.
Security
What happened
New screens can’t leak another client’s data by accident — the database refuses the query.
Decision 04
Log the latest state, not every set
Workout logs keep one row per client and exercise. Simple and fast, but no full history yet.
Tradeoff · Known debt
What happened
Documented as debt in the project context, with full set history planned next.

06

What I learned

Building the product I design changed how I design. A field in a mockup is a column, a policy and an edge case in the database.

Being both the coach and the designer removed every guess. I knew which screens I open ten times a day and which ones I never touch.

The best test user for a coaching app is a coach who trains real clients with it every week.

The biggest lesson was writing things down: a project-context file and a session roadmap made it possible to pick the work up after weeks away.
